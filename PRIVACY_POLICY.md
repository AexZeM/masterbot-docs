# Privacy Policy

**Last Updated:** May 27, 2026

This Privacy Policy explains how this custom Discord application ("the Bot") collects and uses data within the server. 

### 1. Data Collection
The Bot collects and processes the following information to function properly:
* **Discord IDs:** User IDs, Role IDs, and Channel IDs to execute commands and manage permissions.
* **User Inputs:** Data submitted directly through bot commands, forms, or ticket systems (such as application responses).
* **Audit Logs:** The Bot temporarily reads server audit logs strictly for moderation and security features.

### 2. Data Usage
All collected data is used exclusively for the internal management, moderation, and automation of the server. The Bot connects to the server's specific game API to sync basic player statistics.

### 3. Data Storage and Sharing
* Data (such as warning logs and application forms) is stored securely in the Bot's local database.
* **No Third-Party Sharing:** Your data is never sold, shared, or distributed to third parties or advertising networks.

### 4. Data Deletion
If you wish to have your data or logs removed from the system, please contact the server administrators.
